# tayori -たより- 概要

最終更新: 2026-08-03
docs/spec-v3.md（実装仕様の一次情報）と、いま動いているコード（app.py / templates/canvas.html / static/sky/canvas.{css,js}）に基づいて整理した、プロダクト全体の紹介文。

## タイトル

tayori -たより-

## サブタイトル

行き先を決めずにことばを放つ場所。自分の何気ない言葉は、誰かにとって救いの手になるかもしれない。

## テーマ

言葉を放つ。自分にとっての当たり前の価値観や言葉が、誰かにとっては意味のあることになるかもしれない。

## コンセプト

匿名の80字を「宙」へ放つ。その言葉が誰と出会うかは、中身ではなく「空気の近さ」で決まる。
色・季節・時刻帯・天気——書かれた時の空気だけを手がかりに、言葉は近い者のもとへ寄っていく
（地名は2026-07-29に地図機能ごと撤去され、`air_distance()` の成分からも外れた。色0.421／季節0.211／時刻0.211／天気0.157の4成分）。

**「中身は誰にも読まれない」という原則は、二度撤回されている。**

1. **AIは「探す」のために本文を読む**（2026-07-29〜）。さらに2026-08-02、探すの**選別**を外部のAI（Gemini）へ渡す経路を用意した（`TAYORI_SEARCH_AI`・既定OFF）。
   ONにすると、**既に匿名公開されていることばだけ**が Google へ送られる。無償枠なのでGoogleのサービス改善・モデル訓練に使われうることを、隠さずポリシー・規約・/about に書いた（/about は旗の状態で文面を出し分ける）。
2. **運営は本文を読む**（2026-08-03）。収益性の検討に必要だという判断で、2026-07-26の「覗き窓を閉じる」を明示的に撤回し、本文つきの分析画面を作り直した。規約第8条とプライバシー第3項を同日改訂して許諾を明記している。

読まれ方は変わっても、**返ってくるものは変わらない**。返事はつかない。数も順位も出ない。読まれたことは、7秒の灯としてだけ書き手に返る。

## 目的

「誰かに何か言われることを恐れずに、思っていることを自由に、安心して話せる場所」
承認や比較のプレッシャーがないまま、自分の内面のことばを記録・見返す、そして時々「知らない誰かの意味になる」体験を提供すること。

つらい内容であっても宙へ出すことを妨げない。ケア判定は掲載可否のゲートにしない、というのが恒久ルール。
検知された場合は、本人にだけ静かに相談窓口（/contact）を一度提示するだけで、投稿そのものはブロックしない。

## 設計の判断基準

- 承認をつくらない（数・順位・ランキングを見せない）
- 比較をつくらない
- 返事をつくらない（会話・SNS的な相互作用を持ち込まない）
- 義務をつくらない（毎日やらせない、通知で追い立てない）
- AIは書き手にならない（生成も要約も添削もしない）。触るのは「近さを測る」「近くないものを捨てる」の二つだけで、書き手を裁かない・順位をつけない・広告に使わない
- **約束の文は、実装より後から直されがち**。だから約束と実装を直結させる（/about は `_search_ai_on()` を見て文面を変える）。外へ出るところは隠さずに書く
- 「見せない」は運用ではなく構造で担保する（経路そのものを作らない）。ただし**運営の閲覧だけは例外**として規約に書いた——付箋・下書き・未掲載・退会済みデータは日常閲覧の対象外、という線はまだ守っている

## 内容

ユーザー全員で一つの言葉の宙をつくる。ただし今は、一つの巨大な宙ではなく
いくつもの小さな閉じた宙（部屋＝21室）に分かれている。一つの海だと放ったことばが全員に溶けて誰にも届かないため。

宙は **一枚の無限キャンバス**（`/mood` → templates/canvas.html）で、部屋は壁ではなく **地形（島）** として置かれている。
引けば宙ぜんたいの地形が見え、寄れば島の中のことばが紙片になって並ぶ。ログインしていなくても宙は見られる
（`/` は未ログインにだけ索引可能な「門」= index.html を返し、ログイン済みは `/mood` へ送る。宙そのものは noindex）。
「放つ」「棚に残す」だけがログインの向こう側にある。

書き手が新しく生み出す行為は「宙へ放つ」の一つだけ。そこから先の「探す」「棚に残す」は、
すでに宙にあることばに対して行う行為であり、新しいことばを生まない。

## 一枚の宙（無限キャンバス）

2026-07-30、「リストを作らない」の線を降ろして宙全体を一枚のキャンバスへ転換し、同日中に切替を完了した。
旧い宙（mood.html＝球面・自転・漂い物理）は同日 `git rm` で物理削除済み。
書く柱・受け止めの行い・栞・読む柱（`?open=`）・降りてきました（arrivals）・灯まで、すべて canvas に載っている。

- **地形は意味の地図**（2026-08-02改・`6053002`）：黄金角の渦をやめ、部屋の重心から古典的MDSで二次元の地図を起こして島を置いた
  （出た並び＝恋愛→友達／学校→仕事／音楽→アート／つらさ→さびしさ）。重心は**名前と中身を半分ずつ**（中身だけだと、人のことばがまだ無い部屋が測れず地図が二つに割れる）。
  座標は `rooms.pos_x/pos_y` に**固定**する——毎日計算し直すと「あの部屋はあっち」の記憶が壊れる
- **気持ちの名の部屋は、大陸を取り巻く環**（2026-08-03・`ebf3987`）：よろこび／かなしみ／つらさ／さびしさ／しずけさ／あたたかさ／こいしさ の7室は、
  埋め込みの構造上どの「出来事の名」からも遠い（群の隔たり÷ばらつき＝2.0前後で、測り方を変えても割れる）。
  地図の一次元目を「遠さ」ではなく**囲み**として読み替え、大陸を取り巻く環にした（`_bend_ring`）。二群の隙間 1453 → 149
- 島の大きさは中身の量から（`islandR = 150 + 62√n`）。間合い `ISL_GAP`=150、中心へ寄せる弱い重み `ISL_GRAV`=0.006。
  ことばの座標はサーバが決定論で配る単位円（色相＝島の中の方位、半径＝`sqrt(hash)`）＝**全員が同じ宙を見る**。生の空気成分は配らない。
  他の部屋にも掛かることば（またぐことば）は、遠景でも相手の島の側へ寄る
- **降りた島の束は水平の帯**（2026-08-03「ひとつづきの宙」。8/2の円 `f701bbf` を置き換えた）：段高一定・全段同じ幅で、短冊は段の**中心線に上下センター**＝丈の違いが「切れ」ではなく「揺れ」として読める。横に動けば読み進む・縦は段の乗り換え。
  並びは新しさではなく**その部屋らしさ**＝中心の段＝この部屋にしかないことば／縁＝他の部屋にも掛かることば（掛かっている相手の島がある側へ寄る）／いちばん外＝流れ着いたもの。
  段数は束の姿が画面の比にいちばん近くなるところ。倍率も島の半径ではなく**束の量**から決める。
  **帯の形は降りた時の眺め（`isl._fitK`）で決め、寄っても変えない**——上限をいまの倍率から出すと、レンズで寄った最中の敷き直し（岸の組み替え）で束が縦長の紐に化ける。
  「島に居る」の判定も半径ではなく**束の箱**（`isl._bw/_bh`）で見る（帯は半径より縦に長い）
- **紙片の寸法は3値スナップ**（2026-08-03・1b）：幅は字数から 1〜3列（70/100/130px）、高さは 152/236/304px の3値。`sizeOf()` が**字数から純関数で**出すので DOM を測らない。
  入り切らないことば（約45字超）は3列×最大丈に固定して**行送り方向（左）へフェード**（`.ovf` の mask。…は使わない）。全文は焦点レンズで読む
- 紙の色は選ばれた色（彩度12以上）なら `hsl(h,24%,90%)` の手染め紙、無彩は生成り3種、漂流物は灰紙
- **流れ込み**：降りた瞬間に一斉整列させず、読み順に 0.03s 刻み（上限0.5s）で席へ流れ着く
- **降りている間は、宙は一つの様式だけになる**（`body.reading`＝まわりの島の字は退く。ただし opacity 0 ではなく **.14**——0だと束の縁からひと漕ぎで何も無い闇に出る）
- **起動はミクロ**：全景ではなく、いちばん新しいことばが昇った島に降りた姿で開く（`?room=` は従来どおりその島へ）
- **タップ＝受け止め**：波紋がひらき、**空気の近い**8語が寄る（`/api/sky/near`。意味は使わない＝探すの領分）。
  行いの札はそのことばの左下に添う（棚にとっておく／もう見ない。未ログインは「はじめる」）
- **焦点レンズ（近）**（2026-08-03・1d）：島に降りて一枚に触れると、その紙が**画面中央へ滑って全文へ**ひらく（`.focus`＝寸法の規律を解く）。隣は席を空けて息をひそめ、出典と行いは滑走の後に左へ添う。
  もうひとつの入り口は倍率＝降りた島で `K>1.30` まで寄ると中央にいちばん近い一枚がひとりでに開き、引けば閉じる（閉じ線は入った倍率から。判定は手が落ち着いてから＝`gesture` の終い）。
  岸の組み替えで席が動いたら `lensAim()` が照準を引き直す（読んでいた紙を見失わない）
- 沈降 `1/(1+months/12)` は**深さ**（墨の薄さ）として描く。flare中は表層へ浮上（`sink≥0.92`）
- 自分のことばも地形に出す（本人の分だけ欠けたら嘘の地形になる）。しるしは付けない。「もう見ない」は効く
- 規約：プライバシーポリシー第4項の「偶然によるものだけ」を「偶然と、書かれた時の空気・経過時間だけ」へ改訂済み

### 頭の帯と、足元の帯（2026-08-02・`04ac08d`）

2026-07-31の「足元にひとつの帯（案A）」を一部撤回し、**常駐の道具を頭へ移した**。

- 頭：左＝名（押せない）／中央＝**検索の器**／右＝**＋書く**とロゴのしるし（戸）
- 足元に残るのは **＋−／現在地の名／灯／「宙へもどる」**（`body.reading` の時だけ立つ）。名は島に居る間はその島の名、全景では「ひとつづきの宙」
- **押せる合図は罫一本だけ**という v3.10 の線は、この三つ（検索・書く・戸）でだけ降ろして角丸の器を使う——理由は「宙の中の物ではなく、宙を見るための道具だから」。宙の中身（ことば・付箋・棚・書く柱）は罫と紙のまま
- **戸（ロゴのメニュー）＝島渡りの正道**：ジャンル一覧（2列・現在地に点）／棚・書架／設定／about・contact／ログアウト。
  紙を敷いた島に降りると周りの島の字は退くので、「読んでいる途中で別の島へ移れない」の答えは戸に置いた

### 引き返す道（2026-08-03・`c7771af`）

- **URLと履歴**：島へ降りるたび `/mood?room=<id>` を pushState（携帯の戻る＝島から宙へ／前の島へ。リロードしても同じ島に立てる）。つまみで出入りした時は replaceState だけ＝履歴を伸ばさない
- **鍵盤**：矢印＝パン、＋/−＝寄り引き、0＝全景、Escape＝島から全景。ハンドラは **capture で登録**する（柱や戸の Escape が閉じた後に走ると、同じ一押しで全景まで引いてしまう）
- **空白の二度叩き＝寄る**（×1.9）。ことばの上では効かせない
- **＋−の押し続け**＝350ms 後に 120ms 間隔で連続

### 重さ（カクツキ）についての恒久ルール

2026-07-31 に「毎フレームのJS」を、2026-08-03 に「JSがreturnしたあとにブラウザがやる仕事」を測って直した。宙の面をさわる時は必ず守る。

1. **継承するCSS変数を、要素の多い根にJSが毎フレーム書かない**（配下の数百のことばの計算済みスタイルが毎フレーム捨てられる）
2. 宙ぜんたいの見え方を変える class（`.far/.near/.crisp`）は**ヒステリシスで挟む**
3. **測るのと書くのを混ぜない**（relax()／sheetLayout() は「全部測る→計算→全部置く」）
4. 間引きは二段（島ごとの `visibility` ＋ 紙片ごとの寸法キャッシュ）。判定は `onScreen()` 一本
5. **遷移させていいのは opacity と transform だけ**。語の面に blur を足さない
6. 寸法（width/height）でアニメしない／`backdrop-filter` の半径を遷移させない／影のぼけも塗り
7. **束ねている箱に opacity を掛けない**（島ごとに描画の面が一枚立つ）。継承変数 `--dim` を置いてことば側で掛ける
8. **`max-content` の箱は、中身を動かす前に寸法を留める**（打鍵の再生が一字ごとに版面を組み直していた＝常時の重さ）
9. **紙片の寸法は倍率にも画面にも依らない**＝一度測れば控えが効く（`fitK` 21.6ms → 0.3ms）
10. **手がふれている間は、急がない仕事を止める**（`body.gesturing` で灯の呼吸と打鍵の書き直しを止める）
11. **見えない所へ並ぶ紙は、流れてこない**（画面外は transform だけ即時）
12. `will-change` は動いている間だけ。立ち上がりは DocumentFragment で

**指の割り当て**（2026-08-03・案A確定）：宙には縦の送りが無いので、ホイールも二本指も全部「寄る・引く」に入っていた。
だが宙でいちばん重い仕事は**倍率を変えること**（世界の紙を全部描き直す）で、いちばん軽いのは**ひきずること**。地図の作法に合わせた——
二本指スクロール／ホイール＝ひきずる、`ctrl/metaKey` の wheel と実機のピンチ＝寄る・引く。
寄り引きの間だけ `body.zooming` でぼけた塗り（光暈・紙の影）を畳む。**島の灯は消さない**（遠景で島を見分ける唯一の色）。

**手元の棚・書架（/me）は段組みをやめた**（2026-08-03・`f9f5743`）：CSS の `columns` は版面ぜんぶを段に割り直す仕組みで、
中の紙が一枚でも丈を変えるたびに走る＝付箋を一枚貼るのに13.0ms。自前で段に割る（「n段に収まる、いちばん低い段の丈」を二分探索）ことで 0.0ms。
`content-visibility:auto` は使うが、**丈は一枚ずつ実寸を渡す**（当て推量に任せると開いた瞬間に面の丈が 35,569px → 49,083px に狂う）。

実測（1280×720・784片／21島）：寄る・引くの1フレーム 5.16ms → 0.13ms、島を渡るたびの `fitK` 21.6ms → 0.3ms、束の滑走で動く紙 62枚 → 19枚。

## 本番の器（2026-08-01〜02に測って直した）

「重い」と「動かない」は別の話だった。**JSは無実**——真因は経路とメモリ。

- **経路**：Cloudflare の無料プランが日本の接続を米西海岸で受けていた（`colo=SJC`・TCP 130ms／Render自前ゾーンのNRTは16ms）。DNS only で Render のホスト名へ直に向けて解いた。
  なお Render のリージョンは Singapore ではなく **Oregon**（`render.yaml` に `region:` の行が無く既定のまま）＝東京edgeからの残り約80msはこれ
- **落ちていた一行**：日次バックアップの `gzip.compress(fh.read())` が202MBのDBを丸ごとメモリへ載せ、RSS 414MB＝Starterの512MBを超えていた。流しながら詰めて流しながら上げる形へ（414MB → 49MB、21.9s → 11.8s）。**メモリを節約したほうが速い**
- **探すの板**：numpy の fp16 は BLAS に載らないので、掛けるたび fp32 へ開き直していた（本番実測3.6秒）。同じ常駐量で開かずに済む **fp32・10万件**（`_DRIFT_SEARCH_MAX`）へ。8ms／102MB
- **不変のものは一度だけ詰める**（ハッシュ付きの静的資産・セッションを持たない人へのランディング）。5.5ms → 0.25ms
- 遠景に積む岸は `_SKY_CANVAS_SHORE_K`=12（降りた島は `_SKY_SHORE_K`=32 のまま＝降りたあとの見え方は変えていない）。`/api/sky/canvas` は gzip後 111KB → 40KB
- **ディスク付きサービスはデプロイのたびに数十秒の502窓が出る**（1台しかディスクを掴めない）＝デプロイ直後の「動かない」は異常ではない
- 天井は **0.5CPU / 512MB**。板102MB＋DBのページキャッシュで余白はもう少ない

## まだ決めていないこと

- **探すのAI選別（`TAYORI_SEARCH_AI`）を本番でONにするか**：コードと規約・ポリシー・/about の文面は揃っている。ONにすると本文が Google へ渡り（無償枠＝訓練に使われうる）、初回の待ちが2〜4秒つく
- **要約行（S6）の「縦書き／横書き」が送信値と一致していない**：`/api/letters` の `vertical` は 1 固定（漂う姿は必ず縦書き）で、向きは入力欄だけの設定。payload を直すか、要約から向きを外すか
- **印（mark）**：API（`/api/sky/word/<h>/mark`）は生きているが、canvas に導線が無い＝いまUIから押せる場所が無い。畳むか、灯とは別のしるしとして戻すか
- サーバ側に残った**旧・漂い選抜**（`/api/sky`・`_build_sky`・デッキ／カーソル）は、探すが `_sky_word` を共有しているため残置。呼び出し元はもう無い
- 棚の上限10個は妥当か
- 「全員で一つの宙」と部屋分割の整合（理念として残すか、言い換えるか）
- 漂流物の**部屋の当たり外れ**：本まるごとで決めているので一節ごとよりずっと素直だが、外れは残る（芥川『毛利先生』→学校は当たり、岡本綺堂『半七捕物帳』→趣味は外れ）。直すのは `scripts/aozora_rooms.py` の `ROOM_MARKS`
- 漂流物の**著者の偏り**：全量なので片数がそのまま出る（豊島与志雄19,217片＝9.4%）。岸は日ごとに入れ替わるが、多く書いた人ほど多く現れる
- `_SKY_N`=9（探すの定員）、`_SKY_RESONANCE_N`=120 の妥当性は未検証
- かな表記のゆれ（静的な語ベクトル表なので表記の橋渡しが弱い）。AI選別はこれを部分的に肩代わりするが、手前の索引そのものは変わっていない
- **実機（iOS Safari）での動きの確認が未了**：自動化ペインは rAF が止まり CSS遷移も t=0 で凍るため、波紋・引き寄せ・打鍵再生・飛行・つまみは実機でしか見えない

沈降カーブは `1/(1+months/12)`（1年で約1/2、3年で約1/4、ゼロにはしない）として2026-07-29時点で決定済み。

**/map は決着済み**：2026-07-29 に畳んだ（commit 3fea3c9。/map・/api/map・map.html を削除、位置カラムは `scripts/migrate_2026_07_29_drop_map_and_trace.py` で drop）。

## 機能

### 放つ

80字を匿名で宙へ放つ。書き手が新しいことばを生む唯一の行為。放つ時は必ずどこかの部屋を選ぶ
（部屋未指定のまま放つ経路は構造として禁じられている＝400 `room_required`）。
放ってから48時間以内は取り消し可能（書架のそのことばの下に開く。戻せない。部屋の鍵は外れない。棚に既にある控えは残る）。

#### 書く柱（UI改善仕様書 v1.0 §2.2 の S1〜S7）

- **S1** 背は一様な膜をやめ、上から下へ濃くなる縦のグラデーションへ
- **S2** 中身を「**どこへ／いろ／かたち**」の三区画に分け、あいだに罫を一本ずつ。必須（本文・どこへ）と任意（いろ・かたち）の境が線で分かる
- **S3** 部屋の選び場所は左揃えの一枚岩（高さ132pxで頭打ち）
- **S4** 色の二本の帯に固定幅34pxのラベル（色相／濃さ）。区画見出し「いろ」の右端に現在色の丸い見本と色名
- **S5** 向きは「縦」「横」を隣り合わせに置く。選択中のみ墨が立つ——セグメントの器は作らない
- **S6** 出口を分ける。柱の下に残るのは「放つ」だけで、引き返しの「とじる」は柱の左上へ。「放つ」の直下に、いま何を放とうとしているかの要約を一行（確認画面は作らない）
- **S7** 告知を二段に。常時見えるのは「匿名のまま漂い、いつか知らない誰かのもとへ。」の一行だけで、打鍵の記録と著作権の一行は「この投稿について」の中へ畳む（初回だけ展開状態で立つ）

#### 題（title）

書き手が付けられる唯一の10字ラベル（任意）。改行・連続空白を畳んで10字で切る。
空なら題は無い。無題のまま漂ってよい＝欠けではない。かつてのタグは廃止し、これに一本化。
題は「一覧でだけ立つ」もので、宙に出ることばには絶対に混ぜない（宙へ配る辞書には題を最初から入れない）。棚と書架では鉤括弧でくくって出す。
題での検索経路も作らない。

#### 気分の色（常時表示）

色相＋トーンの2本のバーが、書く画面に最初からずっと出ている。
放たれることばには必ず色がのるが、バーに一度も触れずに既定色のまま放った場合は「色を選んだ」と数えず、空気の近さの色成分（42.1%）からは外れる。
宙の側でも、選ばれていない色は方位に使わない（＝空気にしない）。

#### 打鍵の実時間再生（TypeTrace）

放ったことばは、打った過程がそのまま宙で再生される。消した文字も、ためらいの間も含めて。書く画面で放つ前に明示している。

- 記録（クライアント）：3文字目が入った時点から。それ以前に消してやり直した分は永久に残らない。イベント列 `[dt, op, ch]`・上限3000イベント
- 保存（サーバ）：検証してzlib圧縮し `trace_z` へ。壊れていれば黙って捨てる
- 再生：間（ま）を実時間に寄せる。短い間はそのまま、長すぎる間は対数で圧縮（上限5秒）
- ローテーション：8秒周期のtickで**視界内かつ近景のことばだけ・一周期3枚まで**。手がふれている間は始めない。打鍵を持たない種のことばは合成再生（IMEの手つき・乱数の種は本文）
- プライバシーの一線：公開経路に流してよいのは `trace_z` だけ。他人の打鍵そのものは配らない

### 部屋（rooms・21室）

一つの巨大な宙だと、放ったことばが全員の海に溶けて誰にも届かない。だから宙をいくつもの小さな閉じた宙に割った。
既定14室に加え、2026-07-31 に**気持ちの名の7室**（よろこび／かなしみ／つらさ／さびしさ／しずけさ／あたたかさ／こいしさ）を新設した。人もここへ放てる。

| 規則 | 理由 |
|---|---|
| 誰でも作れるが一人ひとつだけ。数えるのは「今持っている数」 | 打ち間違えて作り直せるように |
| 同じ名前は、エラーにせず既存の部屋へ案内 | 拒絶で終わらせない |
| 消せるのは、まだ誰の声も入っていない空の部屋だけ。他人のことばが初めて入った瞬間に鍵がかかる | 放たれたことばは書いた人のものではない |

球面配置と自転（2026-07-27〜28）は、一枚の宙への転換（2026-07-30）とともに退役した。
いまの部屋は無限キャンバス上の島で、席は意味の地図から決まり `rooms.pos_x/pos_y` に固定される。倍率の数字は画面に出さない。
ジャンル名（島の名）はいつでもその島への戸で、タップすると飛ぶ——ただし**降りている島の名だけは指を受けない**（そこは読む面で、主役は紙）。
見えていない島へは、ロゴの戸の中に並ぶ名から降りられる。

#### 部屋の灯（lights）

一覧が返すのは名前と灯の色（最大3・新しい順）だけ。本文も題もidも件数も返さない。
人のことばがまだ無い部屋も、流れ着いたことばの色で灯る（2026-08-02・`cb85bb1`）。
誰かがその部屋のことばに触れている間だけ、灯が呼吸する（手がふれている間は呼吸を止める＝重さの都合）。

### 出会う

#### 空気の近さ（air_distance）

意味には一切触れず、以下の成分だけで距離を測る。

| 成分 | 重み | 中身 |
|---|---|---|
| 色 | 42.1% | 気分の色相の距離 |
| 季節 | 21.1% | 春夏秋冬の環状距離 |
| 時刻帯 | 21.1% | 朝昼夕夜の環状距離 |
| 天気 | 15.7% | 一致0／近い天気は表で補間 |

欠けている成分は外し、残りの重みで再正規化する。何も比べられなければ0.5（中立）。
「探す」を自分から呼び出した時だけ、意味の項が取り分85%で混ざる（既定では0）。
一枚の宙では、この距離は **受け止めた時に寄る8語**（`/api/sky/near`・同じ島の中だけ・距離もスコアも返さない）に効く。

#### 宙のふるまい

- 島の中の**全ことば**がそこに在る（選抜で間引かない＝いつか出る、ではなく、はじめから在る）
- 沈降：古い言葉は約1年で半分に沈む（ゼロにはならない）。沈みは墨の薄さで言う
- 浮上（flare）：約100日に一度・2〜6時間だけ、古いことばが表層へ戻る
- **漂いの物理（衝突・反射）は持ち込まない**——位置が意味を持つ地形に、動き回る要素は混ぜない
- 一日9枠のデッキ／カーソルは、一枚の宙では消化しない。`_SKY_N`=9 が今も効くのは「探す」の定員として

#### 探す（Semantic Gravity）

頭の帯の検索の器から呼び出す。入力内容をベクトル化し、コサイン類似度で近い言葉を抽出。
**返ってきた片は `.gather` の面に紙片として作り直して並べる**（2026-08-02）——それ以前は「いま画面に載っているDOM」だけを灯していたので、20万片の宙では大半が捨てられていた（実測：11件ヒットして表示0件）。
出どころから席へ飛ばす（FLIP＋タイマ commit。rAF は止まる環境があるので使わない）。

- **範囲は常に宙ぜんたい**（島に降りていても部屋で絞らない）。部屋横断は 2026-07-31 にプライバシーポリシー第4項を改訂して開いた（「探すで出せる範囲が、眺めて出会える範囲を越えない」を明記）
- **絶対値で測る**。ただし**閾値は母数ごとに引く**——でたらめな語（`qqqzzz`）の最大コサインは、人のことば392通では0.190だが、本の一節10万片では0.310（0.22超えが425片）。10万も並べれば雑音にも当たる：

  | 母数 | 下限 |
  |---|---|
  | 人のことば | `_SEM_HIT_MIN`=**0.22** |
  | 本の一節 | `_SEM_HIT_MIN_PD`=**0.35** |
  | 人のことば（AI選別ON時） | `_SEM_HIT_MIN_AI`=**0.12** |

- **下限は「捨てる係」の有無とセットで決める**（恒久ルール）。0.22 は捨てる係がいなかった時代の線で、雑音を入れないために recall を捨てていた。捨てる仕事をAIが引き受けるなら、手前は広く拾ってよい。ただし**本の一節はこの緩和を使わない**（母数10万の雑音がAIに見せる24枠を埋めてしまう）
- **AI選別**（`TAYORI_SEARCH_AI`・既定OFF・Gemini）：AIは**選ぶだけ**。書かない・要約しない・並べ替えない。見せるのは人16＋本8＝**合計24が上限**（ポリシーに書いた数なので必ず切る）。
  AIが一つも選ばなければ0件＝「まだここにありません」——これは失敗ではなく正しい答え。鍵なし・届かない・壊れた答えは全部「通さなかった」ことにして厳しい線の山へ戻す。
  `(ことば, 片のid) → 可否` だけを記憶し、本文は覚えない。探しことばは sha256 の指紋にして原文を持たない。初回2〜4秒／同じ語の2回目20〜100ms
- 意味の取り分は `_AIR_SEM_SHARE`=0.85。残りは閲覧者の今（色・季節・時刻・天気）
- 厳密な上位N件にはしない（`exp(-d/T)`・T=0.18 の重み付き抽選＝「寄ってくる」と「並べられる」の差）。出す総数は人9＋本2＝11で不変だが、**人の空き枠は本が埋める**（人0なら本11）。埋めるのは採り終えた後の余りで、本が人を押し出さない
- 自分のことばと「もう見ない」にしたものは出さない。検索クエリの履歴・類似度スコアは永続化しない
- 入力欄の keydown は必ず `isComposing`（と keyCode 229）を最初に見る——IMEの確定Enterを横取りすると、日本語で打つ人には「探せない」になる

#### 言葉の漂流物（外部テキスト）

青空文庫（著作権切れ・パブリックドメイン）から拾った一節が混ざる。生成も要約もせず、本にある文をそのまま切り出す。
**2026-07-31、1,598片から全量へ**（6,040冊・ふるいを通る全部。ローカルDBで203,994片）。

**在ることと、見えることは別**：在るのは20万片で、探すはその全部に届く（実装上は fp32 の一枚板・上限10万件）。
一度に岸へ上がるのは、遠景で島ごと12片・降りた島で32片。**宙の一日（JST 4:00境界）ごとに総入れ替わり**し、島に降りるたびにその人の手元でだけ組み替わる（`/api/sky/shore`。種に閲覧者を入れない遠景は、全員が同じ岸を見る）。

- 部屋は**本まるごと**を見て決める（`scripts/aozora_rooms.py`・全6,040冊の平均の濃さとの**比**で決める）。一節から当てるのは二度試して二度とも捨てた
- 決め手が無い本の一節は `room_id` を持たず、どの島の岸にも流れ着く（71%）
- 気分の色も持つ（`external_texts.mood_color`）。書かれている語からの引用なら推測ではない、という線で開けた。印の出ない一節は生成りのまま
- TypeTrace再生はせず、淡墨の紙で区別する。受け止めると出典（著者・作品名）が刻印される。外部リンクは張らない

### 触れる

- **灯（ともしび）**：誰かが自分の言葉に触れると、自分の宙に7秒ふわりと灯がともる。誰からかは分からない。回数は数えない。
  降りている島に自分以外の誰かが居る間は、灯が弱く呼吸する（30秒ごとの同じ一本の通信で聞く＝専用の心拍は持たない）
- **印**：その場に残すしるし。APIは残っているが、一枚の宙には導線を移植していない（→「まだ決めていないこと」）

### 残す

- **棚**：出会った言葉を最大10個の名前付きの棚に保存できる。棚から棚へ移せる。宙の側の行いは「棚にとっておく」と「もう見ない」の二つ（探して集まってきた片は島に属さないが、同じ道を通る）
- **書架 `/me?tab=archive`**（旧 `/mine` は301でここへ転送）：自分が過去に放った言葉を自分だけが確認できる。年＋季節でまとまり、季節内は色相順
- 棚も書架も**紙片の段組み**（2026-08-03に CSS columns をやめ、自前で段に割る）。字は墨の濃淡で言う。付箋を貼るとその段だけ伸びて裾は揃わない——板として自然なので揃え直さない
- 非対称の原則：他人には、自分の言葉のその後（誰が棚に残したか等）は永遠に見えない
- **付箋**：書き手のタグではなく、読み手が棚に残す瞬間に貼る私物。保存先は読み手側の `saved_tags`。書き手から辿れる場所に付箋は存在しない

### 守る

- **門番**：既定はキーワード判定（掲載／保留／不掲載の三値）。AIは `TAYORI_MOD_AI=1` の時だけ併用する温存コード。判定は本人に一切告げない。検知された言葉は宙に出さず、本人にだけ降る
- **ケア導線**：投稿直後、その言葉にケアの気配があると判定された時だけ、本人限定で一回きりの一文が出る（/contactへの静かな導線・その場で消せる）
- ケア判定は掲載可否のゲートにしない——つらいことばも宙へ出す、が恒久ルール
- 位置情報を扱う場合はおおまかな地名（丸め座標）だけを保存する規則は今も維持されているが、現在の書くフローはそもそも位置を送っていない

### 見る（運営・2026-08-03）

2026-07-26の「覗き窓を閉じる（運営は本文を読まない）」を撤回して作り直した管理画面。手紙時代の集計（到着／開封／写真／声／AI対話／オンボ）は全部撤去した。

- **書き手ごとの横顔**：ことば数／掲載内訳／平均字数／題つき／縦書き／よく書く部屋top3／時間帯／受けた反応（読・灯・配・棚・帰・消）／色スウォッチ／初回・最終投稿日
- **ことばの一覧（本文つき）**：全文＋書き手＋部屋＋状態＋反応数。名前や語で絞り込み、一覧から直接 掲載／下げる
- **admin ログイン通知**：admin への成功ログインと、admin を狙った失敗（パスワード不一致）を、その場でメール（IP／UA／日時）＋監査ログへ記録
- 規約第8条に閲覧・分析の許諾項、プライバシー第3項を「運営者による閲覧と分析について」へ書き換え。公表は非識別形式に限る。**付箋・下書き・未掲載・退会済みデータは日常閲覧の対象外**

### 届く

- **季節の返却**：放った言葉は、季節が巡ったときに書き手本人のもとへ静かに返ってくる。書いた当時の色・天気・時刻帯とともに提示する。宙では「降りてきました」（arrivals）として立ち、読む柱で開く
- **棚に残された報せ**：自分の言葉が誰かの棚に残された時、一度きりだけ届く（生涯1通。2人目以降の保存では何も起こらない）
- **アカウント**：登録 / ログイン / メール認証（ダブルオプトイン）/ 配信停止
